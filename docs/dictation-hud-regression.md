## 需求与风险

- T1：录音时显示波形；松键后停止收音，保留浮窗，移除波形，显示 `thinking` 与加载动画。
- T2：等待显示不取消识别；尾帧和润色稿完整保留，最终完成后关闭浮窗。
- T3：迟到临时文本不能覆盖 `thinking`，等待期间也不能恢复波形。
- T4：再次录音恢复波形，前段的定稿不能关闭仍在录音的新波形；各段最终按顺序提交。
- T5：长按发送的多渠道使用相同等待显示，直到健康定稿后关闭并发送一次；普通候选选择保持原流程。
- T6：错误及非流式空结果展示真实消息文字，不显示录音波形或思考加载；流式完全空结果按上游立即关闭。即时隐藏不影响下一次显示。

风险：仅修改状态文字但视图仍绘制波形；松键误关整个浮窗；临时回包覆盖提示；旧完成操作关掉新录音；等待文字与错误提示混用。测试使用真实 AppDelegate 停止/完成入口、原生文字/加载控件与 NSHostingView 渲染位图，识别响应和音频帧由既有夹具控制；不使用真实麦克风、不访问供应商、不投递键盘事件。多渠道历史使用隔离的 UserDefaults。
